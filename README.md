## 先定三件事，再点购买

顺序错了，后面要多花冤枉钱。

**网站是什么类型。** 静态页面（个人主页、展示页）和动态站点（WordPress、Typecho、论坛）吃资源的方式完全不同，前者 1 核 1G 够用，后者要考虑数据库常驻内存。

**访客主要在哪。** 访客在国内，就选国内或香港节点；访客在海外，直接买洛杉矶、法兰克福这类海外机房更划算。

**要不要备案。** 只要用中国大陆境内的服务器对外提供网站服务，就得走 ICP 备案。雨云官方文档写得很直白：未完成备案的域名，无法在中国大陆服务器上正常提供网站访问，用 IP 直接访问同样会被拦。

这三件事定了，配置和节点基本就锁死了。

## 配置别买大：各档位的真实适用边界

新手最容易犯的错是听人说“建站至少 2 核 4G”，然后花了三倍的钱跑一个每天几十人访问的博客。参考区间大致是这样：

| 配置 | 大致能扛什么 | 适合谁 |
| --- | --- | --- |
| 1核1G | 静态站、低频访问的 WordPress、Typecho 博客 | 第一个站、练手、个人主页 |
| 2核2G | 带数据库的博客、小型企业站、日均几百 UV | 认真运营的内容站 |
| 2核4G | 中型 WordPress、带插件的商城、Discuz 论坛 | 有并发需求的站点 |
| 4核8G 及以上 | 多站点共存、应用后端、需要跑编译或备份任务 | 开发者、多项目并行 |

两个硬件事实值得先知道：**内存是硬门槛**，PHP + MySQL + Nginx 常驻就要吃掉几百兆，1G 内存能用但不宽裕；**Windows 系统本身占用高**，要装 Windows 建议至少 2G 内存起步，Linux 就没这个包袱。

拿不准就先买最低配试一个月，跑起来监控看内存和带宽水位，不够再弹性升配。云服务器比物理机最大的优势就是这一步可以随时做。

## 节点选择：国内、香港、美国的代价完全不同

这是整篇里最影响后续体验的一个决定。

**中国大陆节点**（浙江宁波、浙江温州、深圳、湖北十堰、江苏宿迁、重庆等）延迟最低，国内访客打开最快。代价是必须备案，而且要过白。雨云官方文档里给出的备案支持范围是：浙江宁波、浙江温州、深圳电信、湖北十堰，支持云服务器 RCS、游戏云 RGS、裸金属 RBM 三类产品，审核一般在 15 到 20 个工作日。另外不同区域的过白方式不一样——浙江宁波和温州是手动过白，广东深圳自动过白，重庆电信、湖北十堰、江苏镇江、浙江绍兴需要提工单申请。绍兴还额外要求提供域名所有人信息，二级域名要单独申请。

**中国香港节点**免备案，物理距离近，延迟对国内用户友好，长期以来是个人站长的折中选择。带宽通常比国内节点窄，这是它的短板。

**美国、日本、德国等海外节点**同样免备案，带宽给得大方，适合面向海外访客的站点，或者干脆用来做开发测试环境。

还有一个容易被忽略的细节：部分节点默认套餐属于 NAT 型，不带独立公网 IP，只给固定数量的端口映射。打算直接用它跑网站的话，下单前确认清楚要不要加购独立公网 IP，别等到部署完才发现访问不了。

## 装环境：三条路，挑省事的那条

**第一条，买机器时直接选预装面板的镜像。** 雨云在创建实例时能选预装了宝塔面板或 1Panel 的系统镜像，通常推荐 Debian 12，开机后按控制台给出的地址、账号、密码登进面板，剩下的装 PHP、MySQL、Nginx、申请证书、一键部署 WordPress 都在浏览器里点完。对没有 Linux 经验的人来说，这条最省事。

**第二条，买纯净系统自己装。** 一台机器的自由度最高，适合要跑 Node.js、Python 或者自定义环境的情况。记得第一步先把安全组端口开出来：80（HTTP）、443（HTTPS）、22（SSH，Windows 是 3389）。很多人部署完打不开网站，问题就出在这，不是程序错了。

**第三条，干脆不用服务器。** 雨云有个云应用 RCA，逻辑是应用即开即用，不用自己配环境。博客（Typecho、Halo）、网盘（可道云、NextCloud）、图床（Chevereto）这类成熟应用可以一键部署，部署完直接给访问地址和登录信息，暂停服务后不再计费。

选哪条路取决于你想不想学这台机器。想学，选第一条；只想快点上线，第三条更直接。

## 域名、解析与 HTTPS

如果用的是国内节点，顺序是：注册并实名认证域名 → 提交 ICP 备案 → 备案通过后到雨云控制台做域名过白 → 解析 A 记录指向服务器 IP。过白时只填主域名，不用带 `http://` 或 `https://`，过白范围覆盖该主域名下所有二级域名。备案通过后信息同步还要 1 到 2 天，别急着在同步完成前测试。

香港和海外节点没有这道流程。域名解析好，装上 SSL 证书（宝塔和 1Panel 都有 Let's Encrypt 一键申请），HTTPS 就能跑起来。

## 几个真正会卡住你的地方

**域名被拦，网站打不开。** 国内节点上，没备案的域名解析过去会被机房拦截，报错信息通常就是“尚未备案”那一套。别怀疑配置，先去备案。

**安全组端口没开。** 80 和 443 是必须的，装宝塔的话还要看面板提示的额外端口。开完再访问。

**硬盘买小了。** 雨云云服务器默认 30GB 系统盘，站点图片多、日志不清理的话很快就会紧张。云盘支持购买后弹性扩容，不用重装机器。

**1G 内存跑不动。** 如果站上装了缓存插件、备份插件、还开着 MySQL 和面板，1G 会明显吃紧。这种时候升配比折腾 swap 划算。

**NAT 机型直接建站。** 前面提过，部分节点默认不带独立公网 IP，能不能用、要不要加购，购买页上会写清楚，花一分钟确认。
